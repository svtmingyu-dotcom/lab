1. AcLayers.dll нужна для совместимости старых программ с Windows. Она может менять результат GetVersionEx() чтобы программа думала что запущена на старой версии Windows.

2. UAC Virtualization это когда Windows перенаправляет некоторые записи старых программ из защищённых папок в папку пользователя. Например файл C:\Windows\system.log может попасть в %LOCALAPPDATA%\VirtualStore\Windows\system.log. У меня в Диспетчере задач для old_core_system.exe было написано «Не разрешено» поэтому виртуализация для этого процесса не используется.

3. Просмотр событий нужен чтобы посмотреть ошибки Windows и программ. Там можно узнать когда произошла ошибка какое приложение сломалось и какой был код ошибки. Это помогает понять из за чего программа перестала работать.
